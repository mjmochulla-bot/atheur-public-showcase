# Implementation plan — recorded before application code

## Inspection

The connected Atheur repository is private. Its current README describes the 3.67 Web Terminal: React/TypeScript/Vite presentation over a local Python/FastAPI API, a Tkinter Windows desk, SQLite paper records, and an authenticated private-network mobile companion. The local historical research desk is older. The connected repository is the reference for current capabilities.

Observed navigation includes Overview, Agents, Trading, Market Intelligence, Performance, Risk Management, System Health and Learning & Telemetry. Its visual language uses a dark navy shell, left navigation, compact financial cards, mint positive states, blue accents and clear paper-environment indicators.

Scout, Risk Analyst and Coordinator are deterministic Python components. They are not three LLMs or continuously running independent services. The original supports paper research and public market observations; live trading was not found. Claims about live execution, returns, cloud operations and commercial readiness are excluded.

## New architecture

A separately initialized Git repository will contain newly written React/TypeScript/Vite code only. Hash navigation supports GitHub Pages without rewrite rules. A pure TypeScript simulation module owns a session-only cash ledger, long spot positions, protective orders and deterministic synthetic market steps. Charts use original SVG rendering. No API adapter or private runtime dependency exists. Refresh resets the session.

Pages: portfolio landing; command center; paper simulator; agent coordination; session analytics; system health; developer mode. Agent messages are scripted educational illustrations. Developer content distinguishes verified private-system facts from this reconstruction.

## Security boundary

No original code, data, logos, binaries, certificates, configuration, prompts or private endpoints will be copied. Only visual conventions and verified high-level facts will be recreated. Production content security policy disables connections. All browser code is inspectable; protection comes from excluding proprietary material, not hiding JavaScript. A copyright notice does not prevent copying.

The original repository stays private and untouched. No remote will be published or deployment enabled. A manual, gated Pages workflow will be prepared. GitHub repository creation depends on authenticated creation capabilities; if unavailable, the isolated local Git repository and private-upload instructions will be provided.

## Validation stages

1. Test pure ledger invariants and synthetic market behavior.
2. Build responsive pages and validate navigation/forms.
3. Test production output, desktop/mobile layouts, keyboard access and network isolation.
4. Scan allowlisted public source, production assets and all new Git history; document scope and limitations. No audit can guarantee that software is impossible to copy.
